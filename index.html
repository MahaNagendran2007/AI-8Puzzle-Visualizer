The 8-Puzzle has eight numbered tiles and one blank on a 3 × 3 grid. The goal is to turn an initial configuration into a goal configuration by sliding tiles adjacent to the blank into it. This app solves it with IDDLS only, running entirely in your browser, and shows every iteration, depth limit and expansion.

Solution summary

    About IDDLS

    IDDLS repeatedly runs depth-limited depth-first search, raising the limit by one after each unsuccessful iteration, until the goal is found or the configured maximum limit is reached.

    Working principle

    1. Begin with depth limit 0.
    2. Search within the current limit from the initial state.
    3. Return the path if the goal is found.
    4. Otherwise increase the limit by one.
    5. Repeat until found or the maximum limit is reached.

    Complexity

    Time O(bd), space O(bd), where b is the branching factor and d the depth of the shallowest solution (standard worst-case bounds).

    Advantages

    • Complete for finite branching factors given a large enough limit.
    • Optimal for equal-cost moves.
    • Memory use is far lower than BFS.

    Limitations

    • Repeats work across iterations.
    • Slow for deep solutions.
    • Needs path cycle checks.
    • A maximum depth can hide deeper solutions.

    Versus BFS and DFS (context only): BFS is optimal but stores a whole frontier; DFS is memory-light but neither optimal nor complete without limits. IDDLS combines BFS's optimality with DFS's memory use. Neither is implemented here.
